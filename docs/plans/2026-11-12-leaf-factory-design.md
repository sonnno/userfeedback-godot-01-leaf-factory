# 《青叶加工厂》设计文档

日期：2026-11-12 · 引擎：Godot 4.7.2（GL Compatibility）· 平台：Windows 键鼠

## 1. 总体架构

核心原则：**模拟与渲染分离**。模拟层为纯 GDScript（RefCounted），不依赖场景树，
可无头测试；渲染/输入层（Node2D/Control）只读取模拟状态并转发玩家操作。

```
sim/sim_types.gd    常量：货物/设备枚举、价格、配方、尺寸
sim/building.gd     单个建筑状态（类型、格子、朝向、缓存、进度）
sim/factory_sim.gd  模拟核心：网格、传送步进、机器加工、经济、目标、序列化
game/game.gd        游戏场景根：持有 sim，驱动渲染循环
game/renderer.gd    把 sim 状态画到屏幕上（机器/传送带/货物精灵、状态动画）
game/camera.gd      镜头移动与缩放
game/build_controller.gd 建造/拆除/选择的鼠标交互与预览
game/texture_gen.gd 运行时生成像素贴图（Image → ImageTexture）
ui/hud.gd           顶栏（金币/收入/目标）、建造面板、设备详情面板
ui/menus.gd         主菜单、暂停菜单、目标完成结算
save/save_manager.gd 存档读写（user://savegame.json）
scenes/main_menu.tscn、scenes/game.tscn  极简场景，界面全代码构建
tests/test_sim.gd   无头模拟测试（SceneTree 脚本）
```

## 2. 模拟模型

- 网格 24×18，格边长 48px。出货口固定在右边缘中间格 (23, 8)，不可拆除。
- 货物：原叶 / 切叶 / 干叶 / 盒茶。设备：传送带、采收机、切割机、烘干机、包装机。
- 朝向：0=右 1=下 2=左 3=上。

### 传送（每 0.25 秒一步）
- 每条传送带最多 1 件货；目标格 = 当前格 + 朝向。
- 一步内每件货最多走一格；用迭代式链式解析：目标格在本步开始时为空、或其货物
  本步也将移走，则可移入（保证满带也能全速流动；死循环带自然堵死）。
- 多带汇入同一格：目标格记录上次放行来源，按确定顺序轮转（交替放行）。
- 目标为机器输入口：类型匹配且对应输入缓存为空 → 进入机器。
- 目标为出货口：切叶/干叶/盒茶结算收入；原叶不收，直接丢弃（无收入）。
- 目标为空地/界外/机器非输入侧/类型不符：货物停留。

### 机器
- 采收机：无输入，每 2s 产 1 原叶入输出缓存（上限 1）。
- 切割机：1 原叶 → 1 切叶，加工 1s。烘干机：1 切叶 → 1 干叶，2s。
- 包装机：左右两侧（相对朝向）各一个独立输入缓存（各缓存 1 干叶），
  两侧齐料后开工，3s 产 1 盒茶入输出缓存。
- 普通机器：输入缓存 1 + 输出缓存 1。输出缓存满或前方传送带被占 → 停机等待，
  腾出后继续（加工计时暂停在原地）。
- 机器在每个传送步尝试把输出缓存推到面前格子。

### 经济
- 初始 600 金。价格：传送带 5 / 采收机 60 / 切割机 80 / 烘干机 100 / 包装机 140。
- 拆除返还原价 80% 向下取整（5→4, 60→48, 80→64, 100→80, 140→112）。
- 售价：切叶 5 / 干叶 12 / 盒茶 30。余额不足或格子被占不能建造。
- 全程货物数量与类型守恒（除出货口结算与确认拆除丢弃外）。

### 目标
- 阶段一：累计卖出 10 干叶 → 阶段二：累计卖出 10 盒茶 → 结算面板
  （累计收入、用时），可关闭继续经营。

## 3. 交互与界面

- 镜头：WASD/方向键 + 中键拖拽平移，滚轮以光标为中心缩放（0.5×–2.5×）。
- 建造：底部面板选设备 → 幽灵预览吸附格子（绿=合法，红=非法并显示原因），
  R 旋转，左键放置（可连续放置），右键取消。拆除模式：点击建筑拆除，
  内部有货的机器先弹确认框（确认后丢弃货物）。无模式时点击机器 → 选中，
  右侧详情面板显示各缓存内容与加工进度条。
- HUD：金币、累计收入、当前目标进度；机器头顶小进度条（加工中动画）与
  堵塞闪烁标记；不同货物/机器用不同形状与配色的像素贴图区分。
- 菜单：主菜单（新游戏/继续/退出）；Esc 暂停菜单（继续/保存/回主菜单），
  暂停时模拟完全停止（模拟只在未暂停时推进，UI 保持响应）。

## 4. 存档

`user://savegame.json`：版本号、金币、累计收入、目标阶段与进度、
每个建筑的类型/格子/朝向/各缓存货物/加工进度、每条传送带上的货物。
读档后从原状态精确继续。主菜单"继续"在无存档时置灰。

## 5. 视觉

运行时程序化生成 32×32 像素贴图（ImageTexture，Nearest 过滤）：
- 传送带：深色底 + 朝向箭头（4 朝向用旋转生成），货物移动时箭头滚动动画。
- 机器：各自底色方块 + 图标化图案 + 朝向箭头；包装机标出左右两个输入口。
- 货物：原叶=绿叶形、切叶=碎叶、干叶=棕色叶、盒茶=小盒，形状颜色均不同。
- 出货口：金色边框特殊格。

## 6. 测试与验证

- `tests/test_sim.gd`（SceneTree 脚本，无头运行）：
  采收→切割→烘干→出货全链路数量与金额守恒；包装机双侧输入与 3s 周期；
  汇流交替放行；下游堵塞停机与恢复；拆除退款取整；存档往返一致。
- 命令：`godot --headless --path . -s res://tests/test_sim.gd`，
  另用 `--quit-after` 做导入与脚本解析检查。
