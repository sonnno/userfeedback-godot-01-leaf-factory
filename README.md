# 青叶加工厂

俯视 2D 自动化茶叶生产经营游戏，Godot 4.7.2，GDScript，支持鼠标 + 键盘。

## 运行

用 Godot 4.7.2 打开本目录（含 `project.godot`），按 F5 运行；或双击导入后运行主场景 `Main.tscn`。

## 玩法与规则

- 地图 24×18 格，右侧中部有固定出货口，不可拆除。
- 设备与周期：
  - 采收机：每 2 秒产 1 份原叶。
  - 切割机：每 1 秒把 1 份原叶切成切叶。
  - 烘干机：每 2 秒把 1 份切叶烘成干叶。
  - 包装机：两个独立侧输入口，每侧各缓存 1 份干叶，每 3 秒产出 1 盒茶。
  - 普通加工机各缓存 1 件输入、1 件输出。
- 传送带：货物逐格移动，每 0.25 秒前进一格，每格最多 1 件；多路汇流按轮转交替放行；下游堵塞时货物停留、设备停机，腾出空间后自动续工。
- 经济：初始 600 金币。传送带/采收机/切割机/烘干机/包装机价格为 5/60/80/100/140；拆除返还 80%（向下取整）。余额不足或格子占用时不能建造。
- 出货口收购：切叶 5、干叶 12、盒茶 30 金币；原叶不收购。只有实际到达的货物才结算。
- 目标：阶段一卖出 10 份干叶，阶段二卖出 10 盒茶；完成后显示经营结果并可继续自由建设。

## 操作

| 操作 | 按键 / 鼠标 |
| --- | --- |
| 选择建造设备 | 鼠标点底部工具条，或数字键 1–5 |
| 拆除模式 | 工具条拆除按钮或数字键 6 |
| 旋转（放置幽灵 / 已选设备） | R |
| 取消模式 / 取消选择 | 右键或 Esc |
| 放置 / 选择设备 | 鼠标左键 |
| 移动镜头 | W A S D / 方向键，或按住鼠标中键拖拽 |
| 缩放镜头 | 鼠标滚轮（以光标为中心） |
| 暂停 | Esc 或 P |

拆除内部仍有货物的设备会先弹确认框，确认后丢弃其中货物。

## 存档

主菜单或暂停菜单点击“保存”，写入 `user://leaf_factory_save.json`。存档保留建筑布局、朝向、在途货物、各设备缓存、加工进度、金币、累计收入、目标进度与镜头状态，恢复后从原状态继续。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `main.gd` | 主控：模拟主循环、加工计时、逐格运输、汇流轮转、堵塞、建造/拆除、镜头、输入、目标与存档调度 |
| `scripts/game_types.gd` | 枚举、常量（网格、周期、价格、收购价、目标数量、存档路径） |
| `scripts/icon_draw.gd` | 自定义绘图：调色板、中文字体、四种货物形状、机器图标、端口与朝向三角 |
| `scripts/world_renderer.gd` | 世界渲染：棋盘格、机器、端口、传送带滚动纹、货物插值、进度条、堵塞脉冲、放置/拆除预览 |
| `scripts/hud.gd` | 界面：顶栏、底部建造工具条、设备检查器、提示气泡、主菜单/暂停/结算/拆除确认弹窗 |
| `scripts/save_system.gd` | JSON 存档读写 |
| `tests/headless_test.gd` | 无头单元测试（66 项断言） |
| `tests/e2e_goal_test.gd` | 端到端目标测试（自动建厂跑满两个阶段） |

## 关键设计约定

- 设备的 `dir` 表示**朝向（输出口方向）**；普通加工机输入口在背面 `(dir+2)`，包装机两个输入口在朝向的左右两侧。
- 运输采用固定 0.25 秒逻辑节拍，所有移动意图先收集、按目标分组、轮转挑一个放行后统一生效，保证货物数量/类型守恒、每格最多一件、汇流公平。
- 传送带上的货物其所在格始终是传送带；一旦移动目标是机器或出货口，当拍立即送达（进缓存或出售），不会停留在非传送带格。
